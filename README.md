## 🚗 ParkPal Okinawa

### 作品概要
学生や保護者が、学校や塾の周辺にある駐車場を探しやすくするために制作したアプリです。

### ✨ 主な機能
- 学校・塾などの目的地周辺にある駐車場を検索
- 地図・一覧・詳細画面で駐車場の情報を確認
- 無料・有料・屋内・施設・バリアフリーの条件で絞り込み
- 日本語・英語・中国語（簡体字・繁体字）・韓国語に対応

### 🍀 工夫したこと
- 沖縄の南部・中部・北部の学校や塾を検索対象にしました。
- 実在する駐車場を対象に、看板・現地・Google上の情報などを確認して掲載しました。
- 利用する人が目的や条件に合わせて探せるよう、絞り込み機能を設けました。
- AIを活用しながら、動作確認と修正を繰り返して制作しました。

### 🌱 今後取り組みたいこと
駐車場の管理者と連携し、防犯カメラの映像から空き状況を判定して、リアルタイムで確認できる機能の実現を目指しています。

### 🌐 アプリのURL
[ParkPal Okinawaを開く](https://parkpal-okinawa.vercel.app/)
